# Instructor Notes

This assumes that you are using the Claude Code plugin. If you are using copilot or some other AI Assistant, you will have to adjust the labs and the material accordingly.

Since the setup of the AI assistant plugin or API being used is unique for every class setting up the environment for a specific tool will have to be the responsibility of the instructor and their support team. 

There are optional slide deck on LLMs and AI in general. These are marked as optional and can be used for any background for students who are not familiar with AI. It is not required for the labs, but it can be used to give students a better understanding of how LLMs work and what they are capable of.

The only lab in this section is the setup for Claude using VSCode. 

Since the setting up of the Claude accounts depend on who is running the class, there are no instructions for that. The lab assumes that the students have already set up their accounts and have access to the API keys.
