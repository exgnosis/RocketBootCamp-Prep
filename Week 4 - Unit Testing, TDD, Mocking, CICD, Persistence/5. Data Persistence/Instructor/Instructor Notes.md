# Instructor Notes

## SQL

The student manual supplied for this section covers more than is required for this class.

Many of the students will probably already have some exposure to SQL and relational databases.  

The following are the sections that should be covered in the manual for this class

## Outline

### RDB Concepts
- The Relational Model of Data - page 19
- Relationships - page 31
- SQL Basics - page 41

### SQL Language
- All Chapter 2, Basic Data Manipulation

### Intermediate SQL Chapter 3
- Constants - page 107
- Compound Condition - page 112
- Other WHERE clause operators - page 118
- Distinct - page 130
- Order by - page 132

### Aggregation - Chapter 5
- Overview all the topics but focus on GROUP BY

### Joins - Chapter 6
- Just cover the joins conceptually. 
- Students should be able to just describe what each type of join is and what it does


That should be more than enough material for an SQL overview.
- Depending on time and the level of the students' familiarity with the material, you can drop or add more content as you see fit.
